# Proyecto

La especificación vive en `workspace/`. El código la cumple, no la define.

Antes de diseñar, crear o trabajar cualquier cosa, seguir la skill
`metodologia` (`.agents/skills/metodologia/SKILL.md`).

| Dónde | Qué hay |
|---|---|
| `workspace/Panel.md` | Punto de partida: tu cola y la lista de flujos |
| `workspace/flujos/` | Lo que debe ser |
| `workspace/decisiones/` | Qué se eligió y por qué |
| `workspace/tareas/` | El puente hacia el código |

No escribir código de una tarea con decisiones abiertas.
